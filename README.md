# Estrutura de Dados em Java

Repositório dedicado aos meus estudos e atividades práticas da disciplina de **Estrutura de Dados**, no curso de Ciência da Computação da **Universidade de Fortaleza — Unifor**.

O objetivo é registrar meu aprendizado e aplicar os conceitos estudados em implementações com Java.

## Objetivos de estudo

- Compreender o funcionamento de listas encadeadas e pilhas.
- Praticar operações de inserção, remoção, busca e percurso.
- Desenvolver soluções utilizando recursividade.
- Trabalhar com nós, referências e organização de dados.
- Aprimorar a lógica de programação e a orientação a objetos.

## Tecnologia

**Java**, com foco na implementação manual das estruturas e no entendimento dos algoritmos.

## Como executar

É necessário ter um **JDK instalado**. Abra os arquivos da atividade desejada em uma IDE ou editor com suporte a Java e execute a classe que contém o método `main`.

Os exercícios devem ser executados individualmente, considerando os arquivos e as dependências de cada atividade.
